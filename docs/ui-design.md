# ZCode Remote Control 伴侣 App · UI 设计规范

> 状态：设计提案（未改代码）。范围：原生 Android（Jetpack Compose），平板同构。
> 设计基线：根目录 `DESIGN.md`（Zai Light / Zai Dark token、`text-ui-*` 字号角色、圆角层级）。
> 一句话定位：**离开电脑后，用 30 秒确认 Agent 做得对不对，并推进下一步。**

---

## 0. 产品判断

### 0.1 三个真实时刻

| 时刻 | 用户状态 | 页面必须回答的问题 | 成功标准 |
| --- | --- | --- | --- |
| 离席瞄一眼 | 站着、单手、10 秒 | 现在有什么需要我？ | 首屏可见，不用点进去 |
| 被通知叫回来 | 有明确事件（审批/完成/出错） | 它卡在哪、要我做啥？ | ≤2 次点击完成审批或回复 |
| 主动下指令 | 坐车/走路，想追加需求 | 它现在做到哪了？ | 看到最新进展后可直接输入 |

### 0.2 不做什么

- 不做桌面端镜像：不放大侧栏、不搬文件树、不做多窗口/分屏管理。
- 不做通用聊天 App：没有「新建对话」宇宙，对话永远挂在任务与设备之下。
- 不内嵌终端：执行过程用**结构化步骤 + 可展开日志尾部**表达，完整终端留给桌面端。
- 不在手机端新建 workspace / SSH / Docker 会话：只 attach 桌面已有的 host。

### 0.3 四条设计原则

1. **状态先于内容**：先看见「运行中 / 需要你 / 出错」，再读任务标题。
2. **常态不着色**：只有进行中、需要你、出错三类状态使用彩色；完成/空闲退回中性层级，避免整屏红绿灯。
3. **过程可折叠，结果可核对**：工作过程默认折叠成一行摘要，Diff/产物作为「结果」单独呈现。
4. **弱网不白屏**：先渲染缓存快照，再用顶部细条表达「恢复中」，绝不用模态框打断。

## 2. 信息架构

### 2.1 导航结构

```text
App
├─ 首次启动：配对页 Pairing（无底部导航）
│    ├─ 扫码（CameraX + MLKit，复用现有能力）
│    └─ 粘贴链接 / 最近设备
│
├─ Tab 1 任务 Home
│    ├─ 设备切换 Sheet
│    ├─ 搜索（全屏，任务/项目）
│    ├─ 通知中心（Sheet）
│    └─ 会话详情 Session（push）
│         ├─ 活动日志 Sheet（步骤 + 日志尾）
│         ├─ Diff Sheet（文件列表 + hunk）
│         ├─ 审批 Sheet（命令详情 / 选项）
│         └─ 文件与产物 Sheet
│
├─ Tab 2 设备 Devices
│    ├─ 添加设备（扫码 / 粘贴）
│    └─ 设备详情（连接质量、workspace、保活）
│
└─ Tab 3 我的 Settings
     ├─ 通知（审批 / 完成 / 出错）
     ├─ 后台与保活
     ├─ 外观（系统 / 深色 / 浅色）
     ├─ 连接诊断（日志导出）
     └─ 关于 / 开源许可
```

### 2.2 页面职责

| 页面 | 唯一职责 | 关键状态 |
| --- | --- | --- |
| 配对 | 把手机和一台桌面 host 绑定 | 扫码中 / 校验失败 / 过期 / 成功 |
| 任务 | 跨设备、跨项目的任务总览 | 加载 / 空 / 离线 / 有审批 / 筛选 |
| 会话 | 看进展 + 审批 + 下指令 | 连接中 / 实时 / 恢复中 / 只读 / 已结束 |
| 设备 | 管理连接与保活 | 在线（LAN/中继）/ 重连 / 离线 / 失败 |
| 设置 | 通知与外观偏好 | — |

### 2.3 导航规则

- 会话永远是 push，不占 Tab：避免「聊天 App」心智。
- 返回：会话 → 任务列表，保留滚动位置与筛选；系统返回键与左上角行为一致。
- 深链（通知/扫码）直接进入会话时，返回落到任务列表而不是退出 App。
- 首次配对成功后进入任务页，不自动打开任何会话（对齐 Web 远控「扫码初始态不跳聊天」的既有约定）。

## 3. 视觉系统

### 3.1 原则

- **calm / dense / operational**：信息密度靠层级与间距，不靠卡片套卡片。
- 深度用「背景差 + 1px 边框」表达，阴影只给浮层（Sheet / Dialog / 审批 Dock 的边缘）。
- 品牌是**单色**（深色白、浅色黑），彩色只留给状态。现有 `core/design/Theme.kt` 的紫色 `#6C5CE7` 与纯黑 `#121212` 建议整体废弃。
- 圆角按嵌套层级递减：卡片 12 → 内部 8 → 控件 6；Sheet 24、输入框 20 为移动端平台例外。

### 3.2 色板（与 Zai Light / Zai Dark 同源）

| 语义 | Zai Dark | Zai Light | 用途 |
| --- | --- | --- | --- |
| background | `#161616` | `#F8F8F8` | 页面根 |
| panel | `#202020` | `#FFFFFF` | 顶栏、底部栏 |
| card | `#2B2B2B` | `#FFFFFF` | 卡片、Sheet 内容 |
| input | `#2B2B2B` | `#FFFFFF` | 输入框、代码块底 |
| border | `rgba(255,255,255,.10)` | `rgba(13,13,13,.10)` | 1px 分隔 |
| hover / selected | `rgba(255,255,255,.06)` | `rgba(13,13,13,.05)` | 按压、选中 |
| text | `#E5E5E5` | `#404040` | 正文 |
| text-secondary | `neutral 60%` → `#9A9A9A` | `neutral 60%` → `#8A8A8A` | 元信息 |
| text-tertiary | `neutral 30%` → `#636363` | `neutral 40%` → `#AEAEAE` | 占位、极弱信息 |
| brand | `#FFFFFF` | `#000000` | 主按钮、强调图标 |
| accent | `#001D3D` | `#EBF4FF` | 选中底、引用块（极弱） |

状态色（唯一高饱和来源）：

| 语义 | Dark | Light | 使用 |
| --- | --- | --- | --- |
| running 运行中 | `#4ADE80` | `#16A34A` | 圆点、计时、进度 |
| attention 需要你 | `#FBBF24` / 底 `rgba(251,191,36,.14)` | `#B45309` / 底 `#FFFBEB` | 审批、等待回答 |
| error 出错 | `#F87171` / 底 `rgba(248,113,113,.12)` | `#DC2626` / 底 `#FEF2F2` | 失败、断连 |
| queued 排队/准备 | `#38BDF8` | `#0284C7` | 排队、准备中 |
| done 完成 | text-tertiary + ✓ | 同左 | 不加彩色 |
| diff added | `#4ADE80` / 底 12% | `#16A34A` / 底 `#ECFDF5` | 仅 Diff |
| diff removed | `#F87171` / 底 12% | `#DC2626` / 底 `#FEF2F2` | 仅 Diff |

规则：

- 状态必须「颜色 + 文案 + 图形」三重编码，不允许只靠颜色。
- 同一状态在任务列表、会话头部、通知文案使用同一组色与同一套词。
- 禁止用 success/destructive 色做装饰；完成态不着绿。

### 3.3 字体

对齐 `text-ui-*` 角色，按移动端可读性设定最小 11sp（原生端不套 Tailwind 类名，但角色一一对应）：

| 角色 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `ui-xl` | 18 / 24 | 600 | 页面标题、配对标题 |
| `ui-lg` | 16 / 22 | 600 | 卡片主标题、空态标题 |
| `ui-base` | 14 / 21 | 400 | 正文、消息正文（聊天行 14 / 22） |
| `ui-caption` | 13 / 18 | 400/500 | 辅助说明、任务预览 |
| `ui-sm` | 12 / 16 | 400/500 | 元信息、时间、文件名 |
| `ui-xs` | 11 / 14 | 500 | 状态胶囊、计数、Diff 统计 |
| mono | 12 / 18 | 400 | 路径、命令、分支、哈希 |

- 字体族：系统 sans（中文回退 MiSans/HarmonyOS Sans），等宽用 `FontFamily.Monospace`。
- 中文正文行高 ≥1.5；不使用全大写英文标签。
- 全局支持系统字体缩放：`sp`，布局不写死文字高度；200% 下标题允许两行。

### 3.4 间距 / 圆角 / 触控

- 4dp 栅格；页面左右 16；卡片内边距 14–16；列表项间距 8；区块间距 24。
- 顶栏 52dp，底部导航 56dp + 系统安全区；会话输入栏最小 52dp。
- 触控目标 ≥48dp（视觉可以更小，热区补齐）；相邻可点元素间距 ≥8dp。
- 圆角：卡片 12、内部块 8、胶囊 full、输入框 20、Sheet 24、Dialog 16。
- 图标：20/24dp，线性 1.75px 描边，使用同一套图标（lucide 路径或 Material Symbols Rounded）；**禁止 emoji 充当图标**（当前 `🔧`、`●`、`➤` 需替换）。

### 3.5 深浅色

- **深色是主体验**（Zai Dark）：默认跟随系统，可在设置强制浅色。
- 深色不用纯黑，卡片比背景亮一级（`#161616 → #2B2B2B`），通过边框而非阴影分层。
- 浅色同构：`#F8F8F8` 页面 + 白色卡片 + 10% 黑边框；状态色用 600/700，底色用 50 级浅底。
- 浮层遮罩：深色 45% 黑，浅色 30% 黑；Sheet 顶部 1px 边框 + 24dp 圆角。
- 禁用 Material You 动态取色，避免品牌被系统色覆盖。

### 3.6 动效

| 场景 | 规格 |
| --- | --- |
| 运行中圆点 | 1.6s 呼吸（透明度 1→.45→1），仅前台可见 |
| 流式光标 | 1s 闪烁；文字追加不做逐字动画 |
| 折叠/展开（已工作） | `animateContentSize` 180ms，缓出 |
| Sheet | M3 默认弹簧，≤300ms；拖拽跟手 |
| 审批 Dock 出现 | 上移 12dp + 淡入 180ms |
| 列表插入 | `animateItem` 120ms，不做整列表错峰 |
| 降级 | 系统「减弱动态效果」时关闭呼吸与光标闪烁，只保留状态切换 |

## 4. 状态系统

### 4.1 设备连接

| 状态 | 表达 | 文案 | 可做操作 |
| --- | --- | --- | --- |
| connecting | 转圈 + 中性 | 连接中… | 取消 |
| online (LAN) | 绿点 | 已连接 · 局域网 18ms | 正常使用 |
| online (relay) | 绿点 | 已连接 · 中继 | 正常使用，提示延迟 |
| degraded | 琥珀点 + 细条 | 网络较弱，正在恢复… | 继续浏览缓存、重试 |
| reconnecting | 转圈 + 细条 | 重连中… | 取消、查看诊断 |
| offline | 灰点 | 离线 · 桌面端未打开 | 重试、唤醒指引 |
| failed | 红点 | 连接失败：<原因> | 重试、换设备、看诊断 |
| closed (window) | 灰点 | 桌面端窗口已关闭 | 在桌面端重新打开 |

### 4.2 任务状态（列表胶囊 / 会话头部共用）

| phase / 条件 | 胶囊文案 | 颜色 | 附加 |
| --- | --- | --- | --- |
| `running` | 运行中 | 绿 | 呼吸点 + 已运行时长 |
| `prewarming` | 准备中 | 蓝 | 转圈 |
| 有 `pendingInteraction` | 需要你 | 琥珀 | 计数 1/2、无动画但高对比 |
| `draft` | 草稿 | 中性 | 无胶囊，仅灰点 |
| 排队（queue>0） | 排队中 | 蓝 | 数字 |
| `completedSuccess` | （无胶囊） | 中性 | ✓ + 相对时间 |
| `completedInterrupted` | 已中断 | 中性 | 灰点 |
| `error` | 出错 | 红 | 可打开错误详情 |
| 后台工作（hasBackgroundWork） | 后台运行 | 绿（弱） | 副行小图标，不影响主胶囊 |

排序：需要你 > 运行中 > 其余按更新时间倒序；时间分组内同样遵守。

### 4.3 会话内状态

- 实时 / 快照恢复中 / 只读（桌面端窗口不可用）/ 已结束。
- 断线时**保留全部已加载内容**；顶部 2dp 进度细条 + 头部状态改为「重连中」，不弹模态。
- 恢复完成后在消息流插入一条系统分隔：「已恢复连接 · 补发 3 条」。

### 4.4 文案规则

- 状态 + 下一步，禁止裸错误：「连接失败」→「连接失败：证书无效 · 换用中继或重新扫码」。
- 第二人称、动词开头；不使用「Oops」「哎呀」等语气词。
- 中英文都要经得起变长：胶囊最多 5 个汉字，超出走两行布局而不是截断成「需…」。

## 5. 页面设计

### 5.1 配对页（首次启动）

```text
┌──────────────────────────────┐
│                              │
│           ◇ ZCode            │   ← 单色字标
│                              │
│      连接你的电脑             │   ← 18/24 600
│  在桌面端打开「远程控制」，     │   ← 13/18 次级
│  扫描二维码即可开始。          │
│                              │
│  ┌────────────────────────┐  │
│  │      扫描二维码         │  │   ← 主按钮 52dp
│  └────────────────────────┘  │
│      粘贴链接  ›              │   ← 次按钮（展开输入）
│                              │
│  最近连接                     │
│  ┌────────────────────────┐  │
│  │ 💻 MacBook Pro   12:40 │  │
│  │ 离线 · 2 小时前         │  │
│  └────────────────────────┘  │
│                              │
│  连接只在你的设备之间；        │
│  桌面端可随时断开。            │
└──────────────────────────────┘
```

- 主操作唯一：扫码。粘贴链接为次级展开，不做双主按钮。
- 扫码页：全屏相机 + 240dp 圆角取景框 + 暗角；顶部关闭/手电，底部提示；识别失败用底部内联条，不打断取景。
- 过期/非法链接：留在当前页，显示原因 + 「重新扫码」，不跳 WebView。
- 最近设备最多 5 条，展示设备名、时间、状态；点击直接重连。

### 5.2 任务总览（Home）

```text
┌──────────────────────────────┐
│ ● MacBook Pro ▾      ⌕   ●   │  ← 设备胶囊 / 搜索 / 通知
│ [全部] [需要你 2] [运行中 1]   │  ← 筛选，横向滚动
├──────────────────────────────┤
│ ⚠ 2 个任务需要你 · 查看        │  ← 注意力条（仅全部时）
│                              │
│ 置顶                          │
│ ┌──────────────────────────┐ │
│ │● 修复登录竞态      需要你 │ │
│ │ zcode · main · 2 分钟前   │ │
│ │ 已改 3 个文件  +48 −12    │ │
│ └──────────────────────────┘ │
│ 今天                          │
│ ┌──────────────────────────┐ │
│ │● 补全支付回调      运行中 │ │
│ │ zcode · feat/pay · 8m     │ │
│ │ 正在运行 bun test         │ │
│ └──────────────────────────┘ │
│ ...                          │
└──────────────────────────────┘
```

**顶栏**
- 设备胶囊：状态点 + 设备名（≤140dp，省略）+ ▾；点击打开设备 Sheet；弱网时胶囊内文案变「重连中」。
- 搜索：全屏搜索页（任务标题、项目、路径），最近搜索。
- 通知：Bell + 未读点；点开通知中心 Sheet（审批 / 完成 / 出错分组）。

**筛选**
- 三枚胶囊：全部 / 需要你 / 运行中，带计数；横向滚动，不做下拉菜单。
- 筛选状态在返回时保留；空结果给「清除筛选」。

**注意力条**
- 仅当存在等待项且当前为「全部」时出现；琥珀底 8%，高 56dp，点击切到「需要你」。
- 这是「离席回来」的主入口，优先级高于置顶。

**分组**
- 置顶 → 今天 → 昨天 → 更早；组标题 12sp 次级，不吸顶。
- 相对时间：刚刚 / 12 分钟前 / 14:32 / 昨天 14:32 / 10-12。

**任务卡（核心组件）**

| 区域 | 内容 | 规格 |
| --- | --- | --- |
| 第一行 | 状态点 + 标题 | 15/20 600，1 行省略；未读时标题右侧 6dp 蓝点 |
| 第一行右 | 状态胶囊 / 时间 | 需要你/运行中显示胶囊；其余只显示相对时间 11sp |
| 第二行 | 项目 · 分支 · Diff 统计 | 12sp 次级；分支与 +/− 用 mono 11sp |
| 第三行 | 最近活动 / 最新助手预览 | 13/18 次级，2 行；运行中替换为「正在运行 <命令>」 |
| 容器 | 卡片 | 14dp 内边距，12dp 圆角，1px 边框，最小高 76dp |

状态变体：
- **需要你**：胶囊琥珀 + 卡片边框琥珀 24% + 底 4%；不整卡着色。
- **运行中**：绿点呼吸；第三行活动文案；无进度条（避免假精度）。
- **出错**：红点 + 第二行末尾红字「出错」；标题不变红。
- **完成**：无胶囊；✓ 灰；预览为最终摘要。
- **草稿**：灰点 + 「草稿」弱标签。
- 按压：背景 `hover`；长按弹出「置顶 / 标记已读 / 在桌面端打开」。

**空态 / 加载 / 离线**
- 加载：3–5 个骨架卡（高度稳定，避免跳动），不转全屏 Loading。
- 空：图标 + 「桌面端还没有任务」+ 「在电脑上新建任务，这里会实时出现」+ 次级「查看连接状态」。
- 离线：顶部细条「离线 · 桌面端未打开」+ 重试；列表保留快照并降低饱和度 10%（仍可读）。

### 5.3 会话页

```text
┌──────────────────────────────┐
│ ‹ 修复登录竞态            ⋯  │  ← 标题 15/20；溢出菜单
│ ● 运行中 4m 12s · zcode/main │  ← 状态条，点击进活动
├──────────────────────────────┤
│ 我：把登录竞态修掉，补测试     │  ← 用户气泡右对齐
│                              │
│ 我先看 LoginService 的锁…     │  ← 助手正文（无气泡）
│ ┌ 已工作 4m 12s · 12 步  ▸ ┐ │  ← 折叠过程
│ └──────────────────────────┘ │
│ ┌ 读取 auth/login.ts       ┐ │  ← 工具行（弱化）
│ ┌ 3 个文件已更改  +48 −12  ┐ │  ← Diff 摘要 → Sheet
│ └──────────────────────────┘ │
│ ─── 等待你的操作 ───          │  ← 待决分隔
├──────────────────────────────┤
│ ⚠ 需要你批准                  │  ← Approval Dock（常驻）
│ $ bun test --watch            │
│ [拒绝]              [允许]    │
├──────────────────────────────┤
│ ＋  继续这个任务…        ↑    │  ← 输入栏
└──────────────────────────────┘
```

**头部**
- 返回 + 标题（1 行）+ 溢出（重命名、在桌面端打开、复制会话 ID、断开）。
- 状态条：状态点 + 文案 + 已运行时长 + `项目/分支`（mono 11sp）。点击 → 活动日志 Sheet。
- 状态变体：连接中（标题骨架 + 「连接中…」）/ 恢复中（琥珀 + 细条）/ 只读（「桌面端窗口已关闭」）/ 已结束（「已结束 · 在桌面端继续」）。

**消息流的行类型**

| 行类型 | 呈现 | 交互 |
| --- | --- | --- |
| 用户输入 | 右对齐气泡，最大宽度 84%，底 `input`，圆角 18/6 | 长按复制 |
| 助手正文 | 无气泡，全宽，14/22；支持 Markdown/代码块 | 代码块横向滚动 + 复制 |
| 思考 | 一行「思考 · 12s」+ 展开箭头，默认折叠 | 展开显示 2–3 行摘要 |
| 工具调用 | 单行：图标 + 工具名（mono）+ 参数摘要（mono，省略）+ 状态 | 点击 → 工具详情 Sheet（入参/输出） |
| 工作步骤组 | 连续 ≥3 个工具调用合并为「步骤 N」，由「已工作」承载 | 同上 |
| Diff 摘要 | 卡片：文件数 + 逐文件 +/− | 点击 → Diff Sheet |
| 审批记录 | 解决后一行「已允许 · 你 · 12:31」（弱化） | 无 |
| 错误 | 红底 8% 行内卡 + 原因 + 重试 | 重试 / 诊断 |
| 系统分隔 | 居中 11sp「已恢复连接 · 补发 3 条」 | 无 |

**「已工作」折叠卡（Work Summary）**
- 折叠态一行：`已工作 4m 12s · 12 步`，右侧 `3 文件`；高 44dp，底 `surface`，圆角 10。
- 展开态：竖向时间轴（圆点 + 竖线），步骤 36dp 一行：图标 + 动作 + 结果摘要；底部「查看完整活动」。
- 规则：一次助手回合只出现一次，位于该回合第一条正文之前；回合结束后默认折叠，运行中显示实时活动条而不展开全部步骤。
- 展开时保持滚动锚点（不跳动）。

**运行中活动条**
- 40dp：呼吸点 + 「正在运行 bun test」+ 已用时；点击 → 活动 Sheet（实时日志尾部，mono 12/18，自动滚动，用户上滑即暂停）。
- 这是 OpenHands 式可观测性在手机上的最小化表达：看得到「在干什么」，不搬终端。

**Approval Dock（审批）**
- 位置：输入栏上方常驻，不随消息流滚走；键盘弹起时跟随上移。
- 结构：图标 + 「需要你批准」+ 副文案；命令块（mono，最多 3 行，超出滚动）；说明一行；操作「拒绝 / 允许」+ 溢出「总是允许此命令」。
- 变体：
  - 命令审批：显示完整命令与工作目录；危险命令置顶红字风险提示。
  - 文件修改：显示文件列表 + Diff 入口。
  - 问答（AskUserQuestion）：选项列表（单选/多选）+ 「提交」；自由输入走输入栏。
  - 计划批准：「批准计划」/「要求修改」。
- 多个待决：右上角 `1 / 2` 步进；不允许一次全部批准。
- 操作后 Dock 收起 180ms，流内补一条审批记录。
- 无障碍：出现时 TalkBack 播报「需要你批准，命令 bun test」。

**Diff**
- 摘要卡（流内）：`3 个文件已更改` + 逐文件状态字母（A/M/D）+ 路径 mono + `+48 −12`。
- Diff Sheet：全屏；顶部「更改 · 3 文件」；文件列表 40dp 行（字母着色 + 路径 + 统计）；点文件进 hunk：
  - 行号 + 全宽绿/红 8–12% 底；mono 11.5/18；
  - 长行横向滚动，不软换行；
  - 连续未变行折叠为「⋯ 24 行未变」；
  - 底部「在桌面端打开」/「复制补丁」。
- 颜色只使用 diff token，不复用 success/destructive。

**进度 / 待办**
- 若会话有 Todo：输入栏上方显示 36dp 一行 `3/7 已完成` + 2dp 进度条；点击展开（最多 6 条，其余「查看全部」）。
- 后台工作：状态条显示「后台运行 2」小胶囊，点击进活动 Sheet。

**输入栏**
- 容器 52–120dp，圆角 20，底 `input`，1px 边框；聚焦边框 `border-hover`。
- 结构：`＋`（40dp，附件：图片/文件/引用文件）→ 文本框（14/21，最多 6 行）→ 主按钮（36dp 圆形）。
- 主按钮状态机：
  - 空闲：↑（有文字才可点）。
  - 运行中且无文字：■（停止）。
  - 运行中且有文字：↑（排队发送）+ 上方内联「运行中 · 停止」。
  - 等待审批：↑ 可用，提示「发送将排队」；不锁输入。
  - 离线：禁用，占位「连接已断开，正在重连…」。
- 排队：输入栏下方一行「1 条待发送 · 撤回」。
- `/` 命令：仅 3–4 个（停止、清空、压缩上下文），从输入栏上方浮出，不做全屏面板。
- 键盘：`imePadding` + 列表保持贴底；发送后不收起键盘（连续指令场景）。

**滚动**
- 默认贴底；用户上滑后不再打扰，右下出现「↓ 3 条新消息」浮钮。
- 进入会话先定位到底部；冷启动/恢复时保留上次阅读位置，若在底部则跟随。
- 流式追加不改变用户阅读位置。

### 5.4 设备页

```text
┌──────────────────────────────┐
│ 设备                    ＋    │
│ ┌──────────────────────────┐ │
│ │ ● MacBook Pro            │ │
│ │ macOS · ZCode 3.15       │ │
│ │ 已连接 · 局域网 18ms      │ │
│ │ [zcode] [zcode-web] +2   │ │

│ └──────────────────────────┘ │
│ 其他设备                      │
│ ○ Office-Win11   离线 2h  ›  │
│ ＋ 扫码添加设备（虚线卡）      │
│                              │
│ 如何开启远程控制？  ›         │
│ 后台保持连接          [开关]  │
└──────────────────────────────┘
```

- 当前设备卡：设备名 16/22 600、系统与版本 12sp、连接质量行（LAN/中继 + 延迟）、workspace 胶囊（最多 3 + `+2`）、运行中任务数。
- 操作优先级：「看电脑」（UU 远程，视觉通道）为次主按钮；「断开」为弱操作，二次确认。
- 添加设备：虚线卡 → 复用配对 Sheet（扫码/粘贴）。
- 保活：开关 + 一行说明「保持后台连接，用于接收审批提醒」；未授权通知时显示「去授权」。
- 设备离线：整行降饱和；点击给「在桌面端重新打开远程控制」的指引，不做无意义重试风暴。

### 5.5 设置（我的）

- 顶部：App 名 + 版本 + 当前设备状态（只读）。
- 分组：
  - 通知：审批提醒（高优先级）、任务完成、错误；均给系统声道说明。
  - 后台与保活:前台服务说明、电池优化白名单入口、通知权限状态。
  - 外观：系统 / 深色 / 浅色（默认系统）。
  - 连接：设备列表入口、诊断日志（导出/清空）、协议版本。
  - 关于：开源许可、问题反馈。
- 不放置模型/Provider 管理：这些属于桌面端。

### 5.6 系统层

- **前台服务通知**：低优先级、常驻，「ZCode · MacBook Pro 已连接」，操作「断开」；点击回到最近会话。
- **审批通知**：高优先级、heads-up，文案「需要你批准：bun test」；点击直达会话并展开 Dock；不在通知里直接执行允许/拒绝（避免误触）。
- **完成/出错**：默认优先级，合并同类（「2 个任务已完成」）。
- **回前台摘要**：离开 >5 分钟后回到 App，在任务页顶部插入一张可关闭摘要卡：「离开的 12 分钟 · 2 个完成 · 1 个需要你」。
- **权限**：通知权限在首次进入任务页时以行内卡片申请，不在启动时弹系统框。

### 5.7 平板 / 横屏

- ≥600dp：底部导航换 `NavigationRail`；任务列表限宽 420dp 居中或左置。
- ≥840dp：任务页双栏（列表 380 + 详情占位/最近会话）；会话页正文限宽 720dp，右侧可开 360dp 辅助栏（活动 / Diff）。
- 输入栏限宽 720dp 居中，不拉满 1200dp。
- 横屏手机保持单列，正文限宽 640dp；键盘弹起时头部收起为单行。

## 7. 无障碍与国际化

## 8. Compose 落地建议

### 8.1 设计层文件

```text
core/design/
├─ ZcodeColors.kt      # Zai Light/Dark 语义色 + CompositionLocal(LocalZcodeColors)
├─ ZcodeType.kt        # ui-xl…ui-xs + mono，sp 与行高
├─ ZcodeShape.kt       # 12 / 8 / 6 / 20 / 24
├─ ZcodeSpacing.kt     # 4dp 栅格常量
├─ ZcodeMotion.kt      # 时长、缓动、呼吸动画
└─ components/         # LiveDot、StatusPill、DeviceChip、SectionHeader…
```

`ZcodeTheme` 内同时提供 `MaterialTheme`（colorScheme 由同一组 token 映射，`tonalElevation = 0dp`，surface 不用 tonal tint）与 `LocalZcodeColors`，避免两套颜色并存。

### 8.2 与现有代码的差距

| 现状 | 目标 |
| --- | --- |
| `core/design/Theme.kt` 紫色 + 纯黑/纯白 | Zai 语义色板 + 状态色 |
| 会话卡 = `Card` + 标题/预览/时间 | 三层信息 + 状态胶囊 + Diff 统计 |
| 聊天行 = 气泡 + emoji 图标 | 行类型系统 + 工具卡 + 已工作折叠 |
| 无审批 / Diff / 进度 | Approval Dock + Diff Sheet + Todo 行 |
| 单设备、无切换 | `DeviceChip` + Sheet；单设备时隐藏切换入口，为多设备预留 |

### 8.3 数据缺口（需要协议/归约层补）

1. `SessionItem` 增加：workspace 标签/类型、`unreadAt`、`pinned`、`displayStatus`、`pendingInteraction`、`hasBackgroundWork`、diff 统计、分支名。
2. `ChatRow` 增加：tool 状态与输出、审批请求（`pendingInteractions`）、diff 负载、todo、时间戳。
3. `ChatUi` 目前只透出 `revision/phase`；需把 `state.updated` 中的 `pendingInteractions`、`queue`、`backgroundWorks` 纳入 StateFlow，Approval Dock 才有事实源。
4. 多设备：当前单 `ZcodeConnection`；引入 `DeviceRegistry`（设备列表 + 每设备连接）后 `DeviceChip` 才有切换语义。MVP 可先单设备、隐藏切换。
5. 通知：现有 `RemoteControlKeepAliveService` 服务 WebView；原生链路需要独立前台服务与通知渠道。

### 8.4 性能

- 列表 `key = sessionId` / `rowId`，`contentType` 区分行类型；回调用稳定 lambda 或 `remember`。
- 流式追加只重组变化的行：`ChatRow` 不可变，文本变更产生新对象；Markdown 解析放后台（`core/markdown` 为纯 JVM，可 `withContext(Default)`），按 rowId + 文本哈希缓存。
- 贴底判定沿用现有 `derivedStateOf`，不要每帧读 `layoutInfo`。
- 呼吸动画只在页面 RESUMED 时启动，减少后台耗电。

### 8.5 里程碑

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| M1 | token + 任务页（真实数据 + 骨架/空/离线）+ 设备胶囊 Sheet | 390dp、深/浅色、200% 字体 |
| M2 | 会话页骨架 + 行类型 + 已工作折叠 + 输入状态机 + Approval Dock | 审批 ≤2 次点击；断线保留内容 |
| M3 | Diff Sheet + 活动 Sheet + 恢复摘要 | 弱网恢复不白屏 |
| M4 | 设备页 + 通知/前台服务 + 平板双栏 | 平板 840dp 双栏；通知直达 |
